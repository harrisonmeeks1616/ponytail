What this preview is

The real Harrison OS screens and the real server code, running inside this browser tab with fictional sample data (the Maple Street clinic, Jordan Example). Nothing is sent anywhere.

Works here

  • Capture, review, Today, open tasks, Waiting, Projects, "Where you left off", Memory search, decisions, export.
  • Ask and "Catch me up" in their Not AI mode: answers matched from your saved records.
  • Drafts with the claim check, weekly review, sample calendar and sample company projects (labelled Sample).

Not real in this preview

  • No sign-in, no sync between devices, no offline queue test: the server runs in this tab, so it is always "online".
  • No reminder alerts (no push service). No AI model. No live calendar, PM app or Field Hub connection.
  • Not the installed iPhone app and not a production deployment.

"Skip ahead a week" only moves the app's "last opened" time back eight days, to show the welcome-back view. "Start over" erases this preview's data in this browser.
