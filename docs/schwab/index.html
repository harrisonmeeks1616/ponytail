Field Apps

Charles Schwab Building · Charlotte, NC

Electrical Task Sheets

The superintendent or PM builds each crew's assignment for the day. Crews open it from a text, check off steps, clock their time and send results back.

 Superintendent Daily Report

Daily summary, floor-by-floor crew detail filled in from the task sheets, next steps, risks and decisions for the PM. One tap sends it.

How a day flows

  1. Superintendent (or PM) makes the task sheets and taps Send to crew. Each goes out as a text or email link.
  2. The crew lead opens the link, taps Start, checks off steps, picks a status and taps Send results.
  3. The superintendent opens the results link, reviews it, then taps Fill from task sheets in the Daily Report.
  4. The superintendent taps Send to PM. The PM answers the decisions and sends it back.

Add it to your home screen

iPhone: in Safari tap Share, then Add to Home Screen. If it shows an "Open as Web App" switch, turn it off, so links you get by text land in the same place as the icon. Android: Chrome's menu, then Add to Home screen. After the first open it works with no signal.

Each phone keeps its own records. Links carry the details inside them; nothing is uploaded to a server.
